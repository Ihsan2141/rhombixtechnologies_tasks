# Basic Network Sniffer

## Overview
This project is a Python-based Network Sniffer developed during the Rhombix Technologies Cybersecurity Internship.

The program captures network packets in real time and displays key information, such as the source and destination IP addresses and the protocol type.

## Objective
To understand packet structures, network communication, and traffic analysis using Python and Scapy.

## Tools & Technologies
- Python 3
- Scapy
- Kali Linux

## Features
- Captures live network traffic
- Displays source IP addresses
- Displays destination IP addresses
- Identifies TCP and UDP protocols
- Real-time packet monitoring

## Installation

```bash
sudo apt install python3-scapy
```

## Usage

```bash
python3 network_sniffer.py
```
