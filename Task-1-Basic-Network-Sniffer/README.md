# Basic Network Sniffer

## Objective
Build a Python-based network sniffer that captures and analyzes network traffic.

## Tools Used
- Python 3
- Scapy
- Kali Linux

## Features
- Captures network packets
- Displays Source IP
- Displays Destination IP
- Identifies TCP and UDP protocols
- Real-time packet monitoring

## How to Run

```bash
python3 network_sniffer.py
